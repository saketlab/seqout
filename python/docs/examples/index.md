# Examples

Use these Jupyter notebook guides to learn programmatic workflows in the `seqout` library:

* [Get started](01_getting_started.md): initialize connections, search and filter studies, and load your first dataset.
* [Explore a dataset](02_working_with_a_dataset.md): query study designs, samples, experiments, and runs.
* [Accessions and archives](03_accessions_and_archives.md): map accessions and resolve cross-references across archives.
* [Offline with Parquet](04_offline_with_parquet.md): query database dumps locally using SQL and DuckDB.
* [Counts and metadata](05_counts_and_metadata.md): parse supplementary processed counts files into AnnData objects.
* [Ontologies](06_ontology.md): look up terms, control synonym expansion in search, and map your own labels to ontology IDs.

For terminal-based workflows, see [Command-line examples](command-line.md).
