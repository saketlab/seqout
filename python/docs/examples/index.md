# Examples

Four notebooks, each a full session rather than a snippet. Read them in order
the first time; each assumes the one before it.

- **[Getting started](01_getting_started.ipynb)** — connect, search and filter,
  and open your first dataset. Start here.
- **[Working with a dataset](02_working_with_a_dataset.ipynb)** — every field a
  `Dataset` holds, what is in it, and what you can do with it: the project
  record, samples and their characteristics, library preparations, runs and
  their files, publications, and cross-references.
- **[Accessions and archives](03_accessions_and_archives.ipynb)** — how an
  accession from any of the seven sources resolves to its study, and what
  happens when a link is missing.
- **[Offline with Parquet](04_offline_with_parquet.ipynb)** — reading the same
  data through DuckDB without the API, and the limits of that backend.

- **[Command-line examples](command-line.md)** — the same tasks from the shell.
