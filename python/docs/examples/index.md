# Examples

Use these Jupyter notebook guides to learn programmatic workflows in the `seqout` library:

*   [Getting started](01_getting_started.ipynb) — Initialize connections, search and filter studies, and load your first dataset.
*   [Working with a dataset](02_working_with_a_dataset.ipynb) — Query study designs, samples, experiments, and runs.
*   [Accessions and archives](03_accessions_and_archives.ipynb) — Map accessions and resolve cross-references across archives.
*   [Offline with Parquet](04_offline_with_parquet.ipynb) — Query database dumps locally using SQL and DuckDB.
*   [Counts and metadata](05_counts_and_metadata.ipynb) — Parse supplementary processed counts files into AnnData objects.

For terminal-based workflows, see [Command-line examples](command-line.md).
